# Story 4.2: 노트 내용 기반 자동 요약 생성

## Status

Ready for Review

## Story

**As a** 사용자,
**I want** 노트 내용을 AI가 자동으로 3-6개의 핵심 포인트로 요약해주는 기능,
**so that** 긴 노트의 내용을 빠르게 파악할 수 있다.

## Acceptance Criteria

1. 노트 상세 페이지에 "AI 요약" 버튼이 표시되어야 한다
2. 버튼 클릭 시 Gemini API로 노트 내용이 전송되어야 한다
3. 3-6개의 불릿 포인트로 구성된 요약이 생성되어야 한다
4. 요약 생성 중 로딩 상태가 표시되어야 한다
5. 생성된 요약이 노트 상단에 표시되어야 한다
6. 요약은 노트와 함께 DB에 저장되어야 한다
7. 이미 요약이 있는 노트는 요약을 표시해야 한다
8. 요약 생성 실패 시 에러 메시지가 표시되어야 한다
9. 요약 생성 시간이 10초를 초과하면 타임아웃 처리되어야 한다
10. 노트 내용이 너무 짧으면 (50자 미만) 요약을 생성하지 않아야 한다

### API 호출 함수

```typescript
// lib/ai/summarize.ts
import { getGeminiClient } from './gemini-client'

export async function summarizeNote(content: string): Promise<string> {
    // 최소 길이 검증
    if (content.length < 50) {
        throw new Error('노트가 너무 짧아 요약할 수 없습니다.')
    }

    const client = getGeminiClient()
    
    const prompt = `
다음 노트 내용을 3-6개의 핵심 포인트로 요약해주세요.
각 포인트는 한 문장으로 작성하고, 불릿 포인트(-)로 시작해주세요.

노트 내용:
${content}

요약 형식:
- 첫 번째 핵심 포인트
- 두 번째 핵심 포인트
- 세 번째 핵심 포인트
    `

    const result = await client.generateText({
        prompt,
        config: {
            maxOutputTokens: 500,
            temperature: 0.3, // 일관성을 위해 낮은 온도
        }
    })

    return result.text
}
```

### Server Action

```typescript
// app/notes/[id]/actions.ts
'use server'

import { summarizeNote } from '@/lib/ai/summarize'
import { db } from '@/lib/db/connection'
import { notes } from '@/lib/db/schema/notes'
import { eq } from 'drizzle-orm'
import { createClient } from '@/lib/supabase/server'

export async function generateNoteSummary(noteId: string) {
    try {
        // 인증 확인
        const supabase = await createClient()
        const { data: { user } } = await supabase.auth.getUser()
        
        if (!user) {
            return { success: false, error: '로그인이 필요합니다.' }
        }

        // 노트 조회
        const [note] = await db
            .select()
            .from(notes)
            .where(eq(notes.id, noteId))
            .limit(1)

        if (!note || note.userId !== user.id) {
            return { success: false, error: '노트를 찾을 수 없습니다.' }
        }

        // 요약 생성
        const summary = await summarizeNote(note.content || '')

        // DB 업데이트
        await db
            .update(notes)
            .set({ 
                summary,
                updatedAt: new Date()
            })
            .where(eq(notes.id, noteId))

        return { success: true, summary }
    } catch (error) {
        return {
            success: false,
            error: error instanceof Error ? error.message : '요약 생성 실패'
        }
    }
}
```

### UI 컴포넌트

```typescript
// components/notes/note-summary.tsx
'use client'

import { useState } from 'react'
import { Button } from '@/components/ui/button'
import { Card } from '@/components/ui/card'
import { generateNoteSummary } from '@/app/notes/[id]/actions'

export function NoteSummary({ 
    noteId, 
    initialSummary 
}: { 
    noteId: string
    initialSummary?: string | null
}) {
    const [summary, setSummary] = useState(initialSummary)
    const [loading, setLoading] = useState(false)
    const [error, setError] = useState<string>()

    const handleGenerate = async () => {
        setLoading(true)
        setError(undefined)

        const result = await generateNoteSummary(noteId)

        setLoading(false)

        if (result.success) {
            setSummary(result.summary)
        } else {
            setError(result.error)
        }
    }

    if (summary) {
        return (
            <Card className="p-4 mb-4 bg-blue-50">
                <h3 className="font-semibold mb-2">📝 AI 요약</h3>
                <div className="text-sm whitespace-pre-wrap">{summary}</div>
                <Button 
                    variant="ghost" 
                    size="sm" 
                    onClick={handleGenerate}
                    disabled={loading}
                    className="mt-2"
                >
                    🔄 다시 생성
                </Button>
            </Card>
        )
    }

    return (
        <div className="mb-4">
            <Button 
                onClick={handleGenerate} 
                disabled={loading}
                variant="outline"
            >
                {loading ? '요약 생성 중...' : '✨ AI 요약 생성'}
            </Button>
            {error && (
                <p className="text-sm text-red-600 mt-2">⚠️ {error}</p>
            )}
        </div>
    )
}
```
