# Story 4.X: Gemini Imagen API를 활용한 이미지 생성

## Status

Ready for Review

## Story

**As a** 사용자,
**I want** 텍스트 프롬프트를 입력하여 AI가 이미지를 생성하는 기능,
**so that** 노트와 함께 시각적 콘텐츠를 빠르게 만들 수 있다.

## Acceptance Criteria

1. 텍스트 프롬프트 입력 UI가 제공되어야 한다
2. Imagen API를 통해 이미지가 생성되어야 한다
3. 생성된 이미지가 화면에 표시되어야 한다
4. 생성된 이미지를 다운로드할 수 있어야 한다
5. 이미지 생성 중 로딩 상태가 표시되어야 한다
6. 이미지 생성 실패 시 에러 메시지가 표시되어야 한다
7. 이미지 크기/비율 옵션을 선택할 수 있어야 한다
8. 생성 횟수 제한이 설정되어야 한다
9. API 응답 시간이 30초를 초과하면 타임아웃 처리되어야 한다
10. 생성된 이미지는 base64 또는 URL 형태로 저장되어야 한다

## Dev Notes

### 기술 스택 정보

-   **프레임워크:** Next.js (App Router, Server Actions)
-   **AI API:** Google Imagen API (@google/genai)
-   **이미지 처리:** base64 인코딩/디코딩

### Imagen API 사용법

**이미지 생성 예시:**

```typescript
import { GoogleGenAI } from '@google/genai'

const ai = new GoogleGenAI({ apiKey: process.env.GEMINI_API_KEY })

const response = await ai.models.generateImages({
    model: 'imagen-3.0-generate-002',
    prompt: 'A serene mountain landscape at sunset',
    config: {
        numberOfImages: 1,
        aspectRatio: '16:9',
        includeRaiReason: true,
        personGeneration: 'allow_adult'
    }
})

// 생성된 이미지 저장
if (response.generatedImages) {
    response.generatedImages.forEach((img, i) => {
        if (img.image?.imageBytes) {
            const buffer = Buffer.from(img.image.imageBytes, 'base64')
            // 이미지 저장 또는 표시
        }
    })
}
```

### 타입 정의

```typescript
export interface GenerateImageParams {
    prompt: string
    numberOfImages?: number
    aspectRatio?: '1:1' | '16:9' | '9:16' | '4:3' | '3:4'
    imageSize?: string
}

export interface GenerateImageResponse {
    images: string[] // base64 encoded images
    raiFilteredReason?: string
    latencyMs: number
}
```

### 이미지 옵션

-   **numberOfImages**: 1-4 (기본: 1)
-   **aspectRatio**: '1:1', '16:9', '9:16', '4:3', '3:4'
-   **imageSize**: '256x256', '512x512', '1024x1024'
-   **personGeneration**: 'allow_adult', 'dont_allow'
